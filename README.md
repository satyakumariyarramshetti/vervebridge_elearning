📚 eLearning Platform – Skill Development Portal

A comprehensive and user-friendly eLearning platform designed to promote skill development through interactive content, personalized progress tracking, and a rich user experience. This full-stack application was developed as part of my internship at VerveBridge.

✨ Key Highlights

🖥️ Frontend Development

Built a fully responsive and intuitive user interface using React, HTML, and CSS to deliver a smooth and engaging experience across devices.

🛠️ Backend Development

Developed a secure and scalable backend using Node.js, managing user accounts, course content, and progress with a focus on performance and security.

🗄️ Database Integration

Used MongoDB to structure and store user profiles, course materials, progress data, and user-uploaded resources efficiently.

🚀 Core Features

    🔐 User Registration & OTP Authentication
    Secure signup process with email verification and OTP-based authentication.

    🔑 Password Management
    Easy and secure password reset functionality to maintain account access and safety.

    📈 Progress Tracking
    Real-time tracking of individual user progress across lectures and courses.

    📚 Student Library
    Personalized library for students to upload and manage their study materials including PDFs, videos, and audio files.

    🛠️ Admin Dashboard
    Full-featured admin panel to manage courses and lectures: add, update, or delete with ease.

    🧪 Cross-Browser Testing
    Tested across multiple browsers and devices to ensure consistent UI and performance.

💻 Tech Stack

    Frontend: React, HTML, CSS

    Backend: Node.js, Express.js

    Database: MongoDB

    Authentication: OTP, JWT

    Other Tools: Git, Postman, Vite (if applicable)
